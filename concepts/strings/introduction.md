# Introduction

In Swift, a `String` is an ordered collection of `Character` values representing human-readable text. Swift strings fully support Unicode characters and emoji.

You create a string using a string literal by enclosing text in double quotation marks (`"`).
Special characters use escape sequences—for example, `\n` represents a newline, and `\"` represents an escaped double quotation mark inside a string literal.

An empty string is written as a pair of double quotation marks with no content between them (`""`).

```swift
let hello = "Hello, World!"
let sausage = "Weißwurst is a tasty sausage."
var family = "This is my family: 👨‍👩‍👦‍👦, this is our dog: 🐶"
var empty = ""
```
